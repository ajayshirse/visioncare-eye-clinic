# VisionCare Eye Clinic

Responsive single-page eye clinic website built with HTML, external CSS, and JavaScript.

## Project structure

- `index.html` — page content and sections
- `css/style.css` — responsive layout, visual styling, and animations
- `js/script.js` — mobile menu, scroll reveals, active navigation, counters, and back-to-top

## Run locally

Open `index.html` in a browser. Internet access is used for Google Fonts, Lucide icons, and remote demo photos.
